## iOS 18 兼容适配（部署目标 18.6）

**问题**：工程部署目标为 iOS 18.6，但代码直接调用了 iOS 26 专属 API，编译报
`'glassEffect(_:in:)' is only available in iOS 26.0 or newer`。

**全量清单（编译器迭代扫描，8 处）**：
- `glassEffect` × 5：Button.swift、Collection.swift、ReadingStats.swift、RecentCard.swift、FlipTransition.swift
- `ToolbarSpacer` × 1：AppToolbar.swift
- `tabBarMinimizeBehavior` × 2：iPhoneOSTabs.swift、iPadOSTabs.swift

**方案**：新增 `Utils/ViewModifiers/GlassSurface.swift`（`.glassSurface(_:tone:interactive:in:)`
+ `GlassPressButtonStyle`）与 `TabBarBehavior.swift`（`.minimizesTabBarOnScrollDown()`）。
iOS 26 原样转交 `glassEffect`；iOS 18–25 退化为 Material + 发丝边 + 极淡投影。

**关键设计**：阅读页 `preferredColorScheme` 与纸面**相反**，材质若跟随环境会解析成
同向深浅、把图标吃掉。因此 `GlassSurfaceTone` 由调用方显式给出（`BookContent.readerSurfaceTone`
= `readingTextTone == .dark ? .light : .dark`），不能依赖环境推断。

**验证**：沙箱禁止嵌套 `sandbox-exec`（`(deny default)` 配置 EPERM），`xcodebuild`
的 SwiftPM 解析跑不起来。改用 `swiftc -typecheck` 全模块校验，在 iOS 18.0 / 18.6 / 26.0
三个目标 + `-default-isolation MainActor` + approachable-concurrency 特性下均 0 error 0 warning。
另用最小样例 App 在模拟器实拍验证退化观感（浅纸面浅玻璃黑图标 / 深色页面深玻璃白图标）。

**备注**：18.0 目标同样通过，若想覆盖 18.0–18.5 用户，可把 `IPHONEOS_DEPLOYMENT_TARGET`
从 18.6 下调到 18.0（本次未改动，属发布策略决定）。

## App 图标：AppIcon 缺失 → 改用 Icon Composer 的 vellium.icon

**问题**：资源编译报 `None of the input catalogs contained a matching ... named "AppIcon"`。
`ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`，但 `Assets.xcassets` 里没有
`AppIcon.appiconset`——工程已改用 Icon Composer（`Mini Read/Resources/vellium.icon`），
构建设置却仍指向旧名称。

**修复**：Debug / Release 两个 target 配置里把 `ASSETCATALOG_COMPILER_APPICON_NAME`
改成 `vellium`（.icon 文件名去扩展名）。

**验证**：
- `actool` 手工编译 iphonesimulator / iphoneos 两个平台均 0 error 0 warning，
  产出 `Assets.car` + `vellium60x60@2x.png`(120) + `vellium76x76@2x~ipad.png`(152)；
  Info.plist 得到 `CFBundleIconName = vellium`。
- 搭了个不含 SwiftPM 依赖的最小工程（objectVersion 77 + synchronized group）跑
  `xcodebuild`，确认 Xcode 会**自动**把 `Resources/vellium.icon` 作为输入传给
  `CompileAssetCatalogVariant`，无需手工加入 Resources 阶段，BUILD SUCCEEDED。
- 即 iOS 26 拿到分层 Liquid Glass 图标，iOS 18 自动获得扁平化旧式图标。
