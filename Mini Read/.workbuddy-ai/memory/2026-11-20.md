## 实现「导入与格式 → 手动编辑元数据」

**新增** `Views/Settings/设置分项/2 Library/BookMetadataEditor.swift`：
- `BookMetadataLibraryView`：面板根，@Query 全库（dateAdded 倒序）+ 常驻搜索
  （书名/作者/出版社，localizedStandardContains）+ 空态/无结果态；行用现成的
  `MiniCover`（34×48，ImageIO 降采样 + 共享 NSCache）。
- `BookMetadataEditorView`：Form 三段（封面 / 书籍信息 / 还原）。草稿语义，
  只有「保存」落库；`navigationBarBackButtonHidden` + 自绘「取消」拦未保存改动，
  同时 `.interactiveDismissDisabled(hasChanges)` 防下拉丢草稿。
- `BookCoverStore`：自定义封面写进**书自己的解压目录**
  （`<书>/VelliumCover-<8位随机>.jpg`），删书随目录消失，无需孤儿回收。
  随机后缀是刚需：`CoverThumbnail` 以 URL 为键做内存缓存，同名覆盖会让书架
  一直显示旧封面。**旧文件必须等 modelContext.save() 成功后才删**，
  否则保存失败会留下"库里指向已删除文件"的永久空白封面。
- `EPUBMetadataReader`：复用 `EPUBBook` 重解析 OPF 做「还原原始信息」。

**踩坑**：`-default-isolation MainActor` 下 `EPUBBook` 被推断为主线程隔离，
在 `nonisolated` 函数里调用会产生 2 条警告；给 EPUBBook 加 `nonisolated` 会
连锁到 OPFDocument / ContainerDocument / ManifestItem 共 5 条。故「还原」走
主线程同步解析（几 KB XML），并在注释里写明取舍，保持 0 新增警告。

## 本机绕过 xcodebuild 的构建/实拍方法（可复用）

xcodebuild 的 SwiftPM 清单编译被嵌套 `sandbox-exec` 拦住（提权也无效），
但可以手工编译链接出模拟器可执行文件，替换进已有的 .app 包：

```bash
DERIVED=~/Library/Developer/Xcode/DerivedData/Mini_Read-cofpgqtczcnidhdnciesezkrcnwt
PRODUCTS=$DERIVED/Build/Products/Debug-iphonesimulator
swiftc -disable-sandbox -sdk $(xcrun --sdk iphonesimulator --show-sdk-path) \
  -target arm64-apple-ios18.6-simulator -swift-version 5 -default-isolation MainActor \
  -I $PRODUCTS \
  -Xcc -fmodule-map-file=$DERIVED/Build/Intermediates.noindex/ZipArchive.build/Debug-iphonesimulator/ZipArchive.build/ZipArchive.modulemap \
  -Xcc -I$DERIVED/SourcePackages/checkouts/ZipArchive/SSZipArchive/include \
  @filelist.txt $PRODUCTS/{Kanna,SWXMLHash,ZipArchive}.o -o "Mini Read.app/Mini Read"
```
要点：`-disable-sandbox` 必需（否则 SwiftData 宏插件起不来）；
.app 里要删掉 `Mini Read.debug.dylib` / `__preview.dylib` 再 `codesign -s -`。
临时 UI 实拍可用环境变量在 `TheNewVelliumApp` 里切换根视图（验证后务必删干净）。

## 书架卡片菜单重排 + 元数据编辑入口

**改动**：
- `BookCard.swift`：contextMenu 按 Apple Books 的四段节奏重排——
  `ControlGroup`（收藏 / 加入书单，横排大图标）→ `Edit…`（square.and.pencil）
  → `Save Cover Image` → `删除`（destructive）。新增 `@State isEditingMetadata`，
  sheet 挂在 `body` 的 Group 上（**不能**和「加入书单」的 sheet 挂同一节点，
  同节点两个 `.sheet` 只有最后一个生效）。
- `BookMetadataEditor.swift`：`BookMetadataLibraryView` 增加 `initialBook: bookItem?`，
  非 nil 时跳过列表直接进编辑页（书架长按的场景）；列表拆成私有
  `BookMetadataPickerList`，让 `@Query` 只在真正显示列表时才存在。

**实测发现（既有 bug，未修）**：`bookItem` 存的是**绝对 URL**
（bookExtrSubdir / coverImageURLs…）。模拟器每次 `simctl install` 会换容器 UUID，
库里记录的路径随即失效 → 封面变空白、书打不开。真机上 App 更新一般保持容器路径，
但「卸载重装 / 从备份恢复」同样会踩到。彻底修法是改存相对路径（相对 Documents），
读取时再拼，属独立重构。
