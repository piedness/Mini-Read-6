## Reading App for mini ： 一款为iPad mini 设计开发的本地EPUB电子书阅读器

> 贡献模型：DeepSeek v4pro/v4.1flash、Claude 3.5/5.5、Hy4

## 已实现功能:

### 书库
- EPUB 导入：多选导入、按文件内容去重（跳过 / 保留两者）、失败原因可读
- 自适应书架：封面按原始开本呈现，iPhone 2 列 / iPad 5 列自适应
- 8 种排序（最近阅读、添加时间、书名、拼音、作者、阅读进度）与书名/作者/出版社搜索
- 元数据编辑：书名、作者、出版社、封面，可从原书一键还原
- 书单：创建、重命名、删除、换封面、加书，内置不可删的默认收藏夹
- 存储管理：六类占用明细、按书统计、清理分页缓存与孤儿残留

### 阅读
- 两种翻页：仿真卷曲 / 连续滑动；iPad 双页跨页；音量键翻页
- 排版可调：字体（内置 4 款 + 导入 TTF/OTF）、字号、行距、段距、字距、四边页边距、对齐方式、首行缩进
- 纸面主题：6 种纯色 + 自定义取色 + 2 种纸纹，墨色按纸面亮度自动适配
- 页眉章节标题与页脚页码，位置与格式独立可选
- 扉页与版权页自动排版
- 改字号 / 转屏后按字符锚点还原阅读位置，不丢页
- 目录面板：目录 / 书签 / 笔记三页签，章节树、已读标记、父章进度

### 标注与笔记
- 4 种标注样式（高亮 / 下划线 / 波浪线 / 删除线）× 5 种颜色，透明度可调
- 长按选词、拖柄调整、跨页选区
- 选区菜单：样式、颜色、写笔记、复制、分享、移除标注
- 笔记列表一键跳转并聚焦对应正文
- 标注与笔记导出为 Markdown
- 书签：当前页开关式增删、按阅读顺序排列、精确跳转

### 阅读数据
- 自动记录阅读会话（跨午夜按日切分，短时误触不计）
- 今日时长、连续天数、总时长、预计读完所需时间
- 阅读趋势、时段热力图、单次时长分布、本期书籍、常读作者、阅读洞察
- 首页简报卡与 84 天阅读活跃度

### 外观与系统
- App 强调色、背景（纯色 / 渐变 / 图片）
- 适配 Liquid Glass（iOS 26）与材质退化（iOS 18）
- 设置配置导出 / 导入（JSON）
- Dynamic Type、降低动态效果、VoiceOver 全量支持

### 技术栈
SwiftUI 为主，排版与翻页用 UIKit（UIPageViewController + CoreText）；数据层 SwiftData；
EPUB 解析支持 EPUB 2（NCX）与 EPUB 3（nav）。
