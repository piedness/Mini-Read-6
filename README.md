## Mini Read 6 ： 一款为iPad mini 设计开发的本地EPUB电子书阅读器
> 贡献模型：DeepSeek v4pro/v4.1flash、Claude 3.5/5.5、Hy4

## 已实现功能:

### 书库
- EPUB 导入：多选导入、按文件内容去重（跳过 / 保留两者）、失败原因可读
- 自适应书架：封面按原始开本呈现，列宽自适应（iPhone 约 2 列 / iPad 约 5 列）
- 8 种排序（最近阅读、添加时间新/旧、书名 A-Z、书名拼音、作者、进度未读/已完成优先）与书名/作者/出版社搜索
- 元数据编辑：书名、作者、出版社、封面，可从原书一键还原
- 书单：创建、重命名、删除、换封面、加书，内置不可删的默认书单（My Favorite）
- 存储管理：六类占用明细、按书统计、清理分页缓存与孤儿残留

### 阅读
- 两种翻页：仿真卷曲 / 连续滑动；iPad 双页跨页；音量键翻页
- 排版可调：字体（内置系统 / 宋体 / 黑体 / 霞鹜文楷，可导入 TTF/OTF）、字号、行距、段距、字距、四边页边距、对齐方式、首行缩进
- 纸面主题：6 种纯色 + 自定义取色 + 2 种纸纹，墨色按纸面亮度自动适配
- 页眉章节标题与页脚页码，位置与格式独立可选
- 扉页与版权页自动排版
- 改字号 / 转屏后按字符锚点还原阅读位置，不丢页
- 目录面板：目录 / 书签 / 笔记三页签，章节树、已读标记、父章进度

### 标注与笔记
- 4 种标注样式（高亮 / 下划线 / 波浪线 / 删除线）× 5 种颜色
- 底色透明度可调；线条另设「细 / 标准 / 粗」三档，与底色深浅互不牵连
- 长按按**整句**选中：以中文句号为界，不跨段落；无句号的段落回退到标点之间的短语
- 拖柄调整、跨页选区
- 选区菜单：添加标注（一键套用默认样式与颜色）、样式、颜色、添加/编辑笔记、复制、分享、移除标注
- 右侧留白笔记指示器：竖条 / 圆点两种样式，**点按直接打开该处笔记**，可整体关闭
- 笔记列表一键跳转并聚焦对应正文
- 标注与笔记一键分享为 Markdown 文本
- 书签：当前页开关式增删、按阅读顺序排列、精确跳转

### 阅读数据
- 自动记录阅读会话（跨午夜按日切分，短于 5 秒的误触不计）
- 今日时长、连续天数、总时长、预计读完所需时间
- 阅读趋势、时段热力图、单次时长分布、本期书籍、常读作者、阅读洞察
- 首页简报卡与最近 84 天阅读活跃度

### 外观与系统
- App 强调色、背景（纯色 / 渐变 / 图片）
- 适配 Liquid Glass（iOS 26）与材质退化（iOS 18）
- 设置配置导出 / 导入（JSON）
- Dynamic Type、降低动态效果、VoiceOver 全量支持

### 技术栈
- SwiftUI 为主，排版与翻页用 UIKit：`UIPageViewController` + TextKit
  （一章共享一份 `NSTextStorage` / `NSLayoutManager`，按页切 `NSTextContainer` 分页）
- 数据层 SwiftData；EPUB 解析支持 EPUB 2（NCX）与 EPUB 3（nav）
- 最低 iOS 18.5，Xcode 26 构建；依赖 ZipArchive、SWXMLHash、Kanna
